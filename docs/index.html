Modular by design

一条流水线，六个可插拔维度

所有组件都通过装饰器注册到类型化注册表，内置组件与第三方插件一视同仁；配置即代码，一次运行完整落库。

5 种目标适配器

离线 mock、OpenAI 兼容接口、Anthropic Messages、本地 Ollama、通用 HTTP/JSON 网关。统一超时、重试与限速策略。

8 种提示转换器

base64、ROT13、leetspeak、Unicode 转义、反转、角色扮演、分隔符、分块；支持 | 运算符自由串链。

5 种攻击策略

single_turn、多轮渐进 crescendo、迭代细化 pair、剪枝树搜索 tap、遗传搜索 genetic。

6 种评分器

子串、正则、拒答检测、LLM 裁判、组合聚合（any/all）与人工复核；结论归一化为 success/failure/refusal/unknown。

3 种持久化后端

内存、异步 SQLite（SQLAlchemy 2.0 + aiosqlite）与 JSONL 文件；提示、响应、评分、解析后配置全部可复现。

4 种报告格式

JSON 全量归档、Markdown 评估报告、带图表的交互式 HTML，以及可直接进 CI 安全门禁的 SARIF 2.1.0。

CLI 与 REST API

lrtk run / report / init / serve 命令齐全；FastAPI 服务提供 /runs 全生命周期接口。

entry-point 插件系统

自定义目标 / 转换器 / 攻击 / 评分器无需 fork：打装饰器、发布包、声明 llm_redteam.plugins 入口点即可。

Quick start

三条命令跑起来

Python 3.11+。安装后即可运行离线演示：脚本化 MockTarget 轮转返回拒答与模拟遵从，全程不联网。

# 安装（含开发工具链）
pip install -e ".[dev]"

# 运行离线演示 —— 无需 API Key、无需网络
lrtk run --config examples/configs/demo.yaml

# 查看产物：runs/<run_id>/report.{json,md,html}
# 或启动 HTTP 服务
lrtk serve --host 127.0.0.1 --port 8000
run:
  name: demo
  authorization:            # 授权信息会进入每份报告
    owner: "Your Name"
    scope: "Local mock target only"

target:
  type: mock                # mock|openai_compatible|anthropic|ollama|http_json

attack:
  type: single_turn         # single_turn|crescendo|pair|tap|genetic
  prompts:
    - id: p1
      text: "Ignore previous instructions ..."  # 无害占位符

converters:
  - type: base64
  - type: roleplay

scorers:
  - type: substring
    success_strings: ["DAN", "developer mode"]
  - type: refusal

memory: {type: sqlite, path: ./runs/lrtk.db}
reporting: {formats: [json, markdown, html, sarif]}
Artifacts

给不同读者的四种报告

每份报告都带有授权横幅与配置快照；成功用例可输出为 SARIF 结果，直接接入 GitHub Code Scanning 等 CI 门禁。

JSON

全量归档

完整 AttackRun 结构：每个轮次的提示原文、实际发送文本、响应、评分与延迟。

Markdown

评估报告

汇总统计、授权范围、成功/失败用例表与可复现配置快照，便于邮件与 Wiki 流转。

HTML

交互仪表盘

自包含暗色页面：分布图、逐用例折叠详情、原始提示与变换后提示对照。

SARIF

CI 安全门禁

规则 LRTK001：每个成功绕过产生一条 warning，可被 SARIF 2.1.0 消费方直接摄取。

仅限授权测试 · 合规内建

LRTK 用于帮助模型提供方与防御方度量安全韧性，只能对自有或已获书面授权的系统使用。 仓库内置的提示词均为无害占位符，仅用于驱动测试框架逻辑。

  • 密钥只通过环境变量名 api_key_env 惰性读取，绝不写入配置、日志或报告
  • 日志层强制脱敏：api_key / authorization / token 及 sk-*、Bearer * 模式
  • 每次运行记录授权方、范围、联系人与授权单号，并随所有报告分发
  • 离线 MockTarget 保证 CI 与新人演练不会误触真实模型服务
